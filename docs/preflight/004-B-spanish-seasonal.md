## Additions

### A. Season preview pages (previews only)

Jose wants to see every season's layout now, not only the active one.

- `/season` always shows the season for **today's Central date** (or the evergreen fallback).
- `/season/[id]` (and `/es/temporada/[id]`) renders one named season regardless of date, with a
  visible banner: "Preview of a season that isn't active today."
- These pages exist **only when `VERCEL_ENV !== "production"`**: `generateStaticParams` returns no
  ids in production, so they 404 there. Not in the sitemap, `noindex` everywhere.
- On `/season`, previews only: a small list of links to every season's preview page, so Jose and
  Sayra can click through them.
- A test proves production builds produce no `/season/[id]` routes.

### B. Stock photos for seasons

Jose approved licensed stock photos as stand-ins for the seasons (not for the rest of the site,
which keeps real photos only). Port A1's photo source tracking (a1wrecker `523b079`):
`kind: 'real' | 'stock'`, `sourceUrl`, and the non-failing `STOCK_IN_USE` list. Stock alt text
describes the photo and never claims it is S&A's work. Until Jose supplies files, seasons use the
`{ kind: "none" }` marker; wire the files in a separate `content: season photos` commit. File names
Jose will use: `public/images/seasonal/<season-id>.jpg`.

### C. Seasons running out

Add a **non-failing** warning, `SEASONS_ENDING_SOON`, printed by the gates script when the last
season ends within 60 days. `docs/UPDATING.md` gets "add next year's seasons" steps (copy the year's
entries, change the dates and ids).

### D. One review page for Sayra

`docs/REVIEW.md`, generated by a script (`npm run review`): every visible string as
`path | English | Español`, the season copy included, and the verse version. Regenerated whenever
content changes. This is what Sayra marks up; edits come back as small content commits.

## Acceptance gates (report PASS/FAIL)

- `BUILD_CLEAN` — build, lint and all tests.
- `CONTACT_DELIVERS` (Jose) — a real test from the preview arrives; with a bad API key the form
  shows the failure message and keeps the fields.
- `SEASON_BOUNDARIES` — your midnight-Central and DST tests, listed by name.
- `SEASON_PREVIEWS` — every `/season/[id]` renders on the preview; a production build has none.
- `SPANISH_COMPLETE` — `/es` and `/es/temporada` render with no `[TRANSLATE]` markers; hreflang and
  sitemap list both languages.
- `PRODUCTION_GATES` — expected to fail only on: domain, inquiry email, logo, phone, socials, and
  `TRANSLATIONS_REVIEWED`. Paste the output, plus `STOCK_IN_USE` and `SEASONS_ENDING_SOON`.
